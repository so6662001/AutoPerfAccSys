## 一、核心数据模型（领域实体）

### 1.1 主数据域

| 实体 | 关键字段 | 说明 |
| --- | --- | --- |
| 组织/部门 org | org_id, name, parent | 组织树 |
| 岗位 position | pos_id, name, type(采购/销售) | 岗位类型 |

## 二、功能模块清单

### 模块 1：数据集成中心
- ERP 适配器配置（API/DB/文件）、字段映射
- 行情平台对接（钢银/钢之家）+ 行情价人工导入
- 考勤/奖惩接入
- 每日快照采集调度、数据就绪校验、数据质量监控与告警

### 模块 2：主数据管理
- 组织/岗位/员工、绩效基数维护
- 钢材品规、品规↔行情别名映射
- 客户、业务类型

### 模块 3：指标计算中心
- 取数规则配置（Data DSL）
- 日均库存/应收、周转率自动计算
- 挂价利润 / 净利润 / 成本重估归集
- 预收/应收/预付/应付计息计算（每日余额×日利率）
- 回款账期逐单归集与账期档匹配
- 行情价匹配与价格竞争力/择时评分

### 模块 4：绩效规则配置中心（核心）
- 绩效方案设计器（可视化）
- 公式编辑器（校验 + 版本化）
- 系数档表 / 阶梯表 / 分成比例配置
- 回款账期分档表（吨位单价/提成系数按账期差异化）
- 计息参数配置（预收/应收/预付/应付日利率、阈值、封顶）
- 评分卡配置（基础绩效定性维度）
- 奖惩规则配置
- 规则版本管理与生效期

### 模块 5：核算工作台
- 月度核算跑批（触发/调度）
- 试算/正式核算、批量与单人重算
- 异常清单（缺数、负值、超阈值）
- 核算结果对比（版本差异）

### 模块 6：审批与员工端
- 主管审核、员工确认、申诉复核闭环
- 个人绩效单（构成 + 逐笔下钻）
- 移动端 H5 查询

### 模块 7：报表与看板
- 见下节

### 模块 8：系统管理
- 角色权限（含字段级/数据脱敏）
- 审计日志
- 参数与字典

## 三、角色与权限（含敏感数据保护）

| 角色 | 数据范围 | 关键权限 |
| --- | --- | --- |
| 员工 | 仅本人 | 查看本人绩效单、发起申诉 |
| 主管 | 本团队 | 定性打分、初审、查看团队汇总（可脱敏个人明细） |
| HR/绩效专员 | 授权范围 | 配置规则、跑批、核定、发放 |
| 财务 | 授权范围 | 数据校核、对账（一期只读） |
| 管理层 | 全局 | 看板、汇总（默认脱敏到岗位/团队） |
| 系统管理员 | 平台 | 数据源、权限、主数据；无业务金额审批权 |

**安全设计**：
- 字段级权限：薪酬金额按角色可见/脱敏。
- 数据行级隔离：按组织树限定可见范围。
- 全操作审计：规则变更、核算、核定均留痕。
- 敏感操作双人复核（可选）：规则发布、核定发放。

## 四、报表与看板

| 看板/报表 | 面向 | 内容 |
| --- | --- | --- |
| 个人绩效单 | 员工 | 基础绩效、提成/超额奖、系数、奖惩、最终应发 + 下钻 |
| 团队绩效汇总 | 主管 | 团队达成率、人均提成、排名 |

| 销售业绩看板 | 销售主管/管理层 | 三类业务利润、挂价溢价、应收周转/逾期 |
| 绩效成本分析 | 管理层 | 绩效支出 vs 业务利润、投入产出比 |
| 核算稽核报表 | HR/财务 | 异常清单、规则版本、复算差异、申诉记录 |

## 五、非功能性要求

- **可复算/幂等**：同周期同数据同规则重跑结果一致。
- **性能**：单批数千人核算在分钟级完成；日快照采集不影响 ERP 生产。
- **可扩展**：新增岗位/业务类型不改核心，靠配置扩展。
- **可用性**：核算失败可回滚、断点续跑。
- **合规**：薪酬数据加密存储、访问审计、最小权限。
