# 03 · 销售绩效核算设计

销售业务分三大类：**现货销售、零调业务、直发/民调业务**。考核 = **基础绩效工资 + 利润提成/奖金 + 应收账款考核 + 行政奖惩**。

---

## 一、销售绩效总模型

```
销售绩效总额 = 基础绩效工资 + 利润提成/奖金 - 应收账款考核扣减 + 行政奖惩
其中：
  基础绩效工资 = 绩效基数 × 基础绩效系数(0/0.6/0.8/1.0/1.2)
  利润提成     = f(业务类型)  // 现货 / 零调 / 直发民调 分别计算
  应收扣减     = 扣款模式 或 利息核算模式
```

---

## 二、基础绩效管理

**工作内容（考核维度）**：月度保底销售量、新客户开发、客户维护、日常客情维系。

**量化设计（定量 + 定性混合评分卡）**：

| 维度 | 类型 | 取数/评分方式 |
| --- | --- | --- |
| 月度保底销量 | 定量 | ERP 销量 / 保底目标 → 达成率 |
| 新客户开发 | 定量 | 新增有效成交客户数（首单/激活口径可配置） |
| 客户维护 | 定量+定性 | 老客户复购率/活跃客户数 + 主管评分 |
| 日常客情 | 定性 | 主管/系统评分卡 |

```
基础绩效系数 = 评分卡加权得分 → 映射档位(0 / 0.6 / 0.8 / 1.0 / 1.2)
基础绩效工资 = 绩效基数 × 基础绩效系数
```

- 保底销量未达"最差情况" → 系数可为 0。
- 各维度权重、达成率→系数映射均可配置。

---

## 三、利润提成 / 奖金（按业务类型）

### 3.1 现货销售

现货提成 = **基础量吨位提成（阶梯） + 挂价利润分配**。

**(a) 基础量内 · 吨位固定提成（支持阶梯）**

```
吨位提成 = 阶梯查表(累计销量) 逐档计算
阶梯示例：
  0 ~ 500 吨      → 3 元/吨
  500 ~ 1000 吨   → 5 元/吨 (超出部分)
  > 1000 吨       → 8 元/吨 (超出部分)
```

**(b) 挂价利润分配**

```
挂价利润   = (实际成交价 - 挂牌价) × 实际销售吨位
个人所得   = 挂价利润 × 分配系数
```

- 挂牌价、成交价、吨位来自 ERP；分配系数可按人/团队/业务配置。
- 成交价 < 挂牌价（折价销售）时挂价利润为负，是否扣减可配置。

**现货提成合计** = 吨位提成 + 挂价利润个人所得。

### 3.2 零调业务

按业务净利润分成：

```
业务净利润 = 毛利 + 其他收入 - 其他支出
个人所得   = 业务净利润 × 个人分成比例
```

- 毛利、其他收入/支出按"业务/项目"维度从 ERP 归集。
- 公司与个人按约定百分比分成，比例可配置。

### 3.3 直发 / 民调业务

- 核算逻辑同零调（按净利润分成），**分成系数不同**（独立规则集）。
- 通过"业务类型"字段路由到对应规则集。

### 3.4 三类业务对比

| 业务类型 | 提成基础 | 关键参数 | 特点 |
| --- | --- | --- | --- |
| 现货销售 | 吨位提成(阶梯) + 挂价利润 | 阶梯表、挂牌价、分配系数 | 有库存，量价双驱动 |
| 零调业务 | 业务净利润 | 净利润口径、分成比例 | 撮合/调剂，利润导向 |
| 直发/民调 | 业务净利润 | 分成比例(异于零调) | 直发，逻辑同零调 |

## 四、应收账款考核

应收周转力度与提成挂钩，**两种模式（可按企业择一或分档并用）**：

### 4.1 扣款模式（按回款天数扣提成比例）

```
应收扣减 = 提成 × 扣款比例(回款天数)
示例映射：
  账期内回款            → 扣 0%
  逾期 1~30 天          → 扣 10%
  逾期 31~60 天         → 扣 30%
  逾期 > 60 天          → 扣 50% 或冻结提成
```

### 4.2 利息核算模式（按逾期天数计息）

```
应收利息扣减 = 逾期应收金额 × 日利率(万分之几) × 逾期天数
如：万分之五/天，逾期 40 天，逾期金额 100 万
   → 1,000,000 × 0.0005 × 40 = 20,000 元，从收益中扣除
```

- 日利率、起扣阈值、封顶规则可配置。
- 支持结合"应收周转率"（`销售额 / 日均应收`）做整体健康度评价。

## 五、销售绩效核算示例（月度 · 现货销售员）

绩效基数 6000 元：

| 项目 | 取值 | 说明 |
| --- | --- | --- |
| 基础绩效系数 | 1.0 | 保底销量/新客/客情评分达标 |
| 基础绩效工资 | 6000 | |
| 当月销量 | 800 吨 | |
| 吨位提成(阶梯) | 500×3 + 300×5 = 3000 | |
| 挂价利润 | (成交-挂牌)差 × 800 = 8000 | |
| 分配系数 | 0.7 → 挂价个人所得 5600 | |
| 提成小计 | 3000 + 5600 = 8600 | |
| 应收扣减(逾期20天,扣10%) | −860 | 扣款模式 |
| 行政奖惩 | 0 | |
| **最终应发** | 6000 + 8600 − 860 = **13740** | |

## 六、销售绩效配置要点

- 业务类型主数据（现货/零调/直发/民调）与规则集路由。
- 吨位阶梯表、挂价分配系数、净利润分成比例。
- 净利润口径（其他收入/支出科目映射）。
- 应收考核模式选择与参数（扣款比例表 / 日利率）。
- 基础绩效评分卡（维度、权重、系数映射）。

> 取数与计算实现见 [数据与核算引擎设计](./05-数据与核算引擎设计.md)。
