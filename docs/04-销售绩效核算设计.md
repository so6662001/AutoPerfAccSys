# 03 · 销售绩效核算设计

销售业务分三大类：**现货销售、零调业务、直发/民调业务**。考核 = **基础绩效工资 + 利润提成/奖金 + 应收账款考核 + 行政奖惩**。

---

## 一、销售绩效总模型

```
销售绩效总额 = 基础绩效工资 + 利润提成/奖金 + 预收计息收益 - 应收账款考核扣减 + 行政奖惩
其中：
  基础绩效工资 = 绩效基数 × 基础绩效系数(0/0.6/0.8/1.0/1.2)
  利润提成     = f(业务类型, 回款账期)  // 现货 / 零调 / 直发民调 分别计算，且逐单按账期差异化
  预收计息收益 = 预收账款 × 日利率 × 占用天数 × 分配系数   // 正向激励
  应收扣减     = 扣款模式 或 利息核算模式
```

> **两条资金相关主线**：① 计提口径按"每笔业务的回款账期"差异化（账期长→单价/系数低）；② 预收占用给正向计息收益、应收逾期给扣减计息，二者方向对称。

---

## 二、基础绩效管理

**工作内容（考核维度）**：月度保底销售量、新客户开发、客户维护、日常客情维系。

**量化设计（定量 + 定性混合评分卡）**：

| 维度 | 类型 | 取数/评分方式 |
| --- | --- | --- |
| 月度保底销量 | 定量 | ERP 销量 / 保底目标 → 达成率 |
| 新客户开发 | 定量 | 新增有效成交客户数（首单/激活口径可配置） |
| 客户维护 | 定量+定性 | 老客户复购率/活跃客户数 + 主管评分 |
| 日常客情 | 定性 | 主管/系统评分卡 |

```
基础绩效系数 = 评分卡加权得分 → 映射档位(0 / 0.6 / 0.8 / 1.0 / 1.2)
基础绩效工资 = 绩效基数 × 基础绩效系数
```

- 保底销量未达"最差情况" → 系数可为 0。
- 各维度权重、达成率→系数映射均可配置。

---

## 三、利润提成 / 奖金（按业务类型）

### 3.1 现货销售

现货提成 = **基础量吨位提成（阶梯） + 挂价利润分配**。

**(a) 基础量内 · 吨位提成（支持阶梯 + 回款账期差异化）**

吨位提成需在"销量阶梯"之外，叠加**回款账期**维度：回款账期越长，占用资金越多、风险越高，对应的**吨位提成单价更低或提成系数更低**（现款/预收最高）。因此提成需**按每笔业务（逐单）**结合其约定回款账期核算，而非仅按当月总量。

```
方式一 · 账期分档单价（逐单）
  吨位提成 = Σ_每笔[ 该笔吨位 × 账期档吨位单价(阶梯) ]
  账期档单价示例：
    现款/预收      → 8 元/吨
    账期 ≤ 30 天   → 6 元/吨
    账期 31~60 天  → 4 元/吨
    账期 61~90 天  → 2 元/吨
    账期 > 90 天   → 0 或不予计提

方式二 · 阶梯单价 × 账期系数（逐单）
  吨位提成 = Σ_每笔[ 该笔吨位 × 阶梯单价(累计销量) × 账期提成系数 ]
  账期系数示例：现款1.2 / 30天1.0 / 60天0.7 / 90天0.4 / >90天0
```

- 两种方式由业务择一：方式一直接给账期分档单价；方式二在原销量阶梯上乘账期系数。
- 账期口径：以**约定回款账期**计提，实际回款后再由"应收账款考核"做逾期扣减/计息，两者不重复（约定账期决定单价，逾期与否决定扣减）。
- 阶梯累计销量的口径（是否含账期折算量）可配置。

**(b) 挂价利润分配**

```
挂价利润   = (实际成交价 - 挂牌价) × 实际销售吨位
个人所得   = 挂价利润 × 分配系数
```

- 挂牌价、成交价、吨位来自 ERP；分配系数可按人/团队/业务配置。
- 成交价 < 挂牌价（折价销售）时挂价利润为负，是否扣减可配置。

**现货提成合计** = 吨位提成 + 挂价利润个人所得。

### 3.2 零调业务

按业务净利润分成：

```
业务净利润 = 毛利 + 其他收入 - 其他支出
个人所得   = 业务净利润 × 个人分成比例 × 账期提成系数(逐单)
```

- 毛利、其他收入/支出按"业务/项目"维度从 ERP 归集。
- 公司与个人按约定百分比分成，比例可配置。
- **回款账期差异化**：每笔业务回款账期不同，`账期提成系数`按该笔约定账期取值（现款高、长账期低），逐单计提后汇总。系数档由业务配置。

### 3.3 直发 / 民调业务

- 核算逻辑同零调（按净利润分成），**分成系数不同**（独立规则集），同样叠加逐单账期提成系数。
- 通过"业务类型"字段路由到对应规则集。

### 3.4 回款账期差异化（贯穿各业务类型）

> 回款账期是销售绩效的独立调节维度：**账期越长 → 资金占用与坏账风险越高 → 提成越低**。它按"每笔业务约定账期"生效，与事后逾期考核（第四节）分工不同。

| 业务类型 | 账期作用方式 | 载体 |
| --- | --- | --- |
| 现货销售 | 差异化**吨位提成单价** 或 阶梯单价×**账期系数** | 账期分档单价表 / 账期系数表 |
| 零调 / 直发 / 民调 | 差异化**提成系数**（乘在分成比例上） | 账期提成系数表 |

- 账期分档（现款/预收、≤30、31~60、61~90、>90 天等）与各档单价/系数均可配置、可版本化。
- **口径分工**：约定账期 → 决定"计提多少"（单价/系数）；实际回款是否逾期 → 决定"扣减多少"（第四节）。二者不重复计。

### 3.5 三类业务对比

| 业务类型 | 提成基础 | 关键参数 | 特点 |
| --- | --- | --- | --- |
| 现货销售 | 吨位提成(阶梯×账期) + 挂价利润 | 阶梯表、账期单价/系数、挂牌价、分配系数 | 有库存，量价双驱动 |
| 零调业务 | 业务净利润 × 分成 × 账期系数 | 净利润口径、分成比例、账期系数 | 撮合/调剂，利润导向 |
| 直发/民调 | 业务净利润 × 分成 × 账期系数 | 分成比例(异于零调)、账期系数 | 直发，逻辑同零调 |

## 四、应收账款考核

应收周转力度与提成挂钩，**两种模式（可按企业择一或分档并用）**：

### 4.1 扣款模式（按回款天数扣提成比例）

```
应收扣减 = 提成 × 扣款比例(回款天数)
示例映射：
  账期内回款            → 扣 0%
  逾期 1~30 天          → 扣 10%
  逾期 31~60 天         → 扣 30%
  逾期 > 60 天          → 扣 50% 或冻结提成
```

### 4.2 利息核算模式（按逾期天数计息）

```
应收利息扣减 = 逾期应收金额 × 日利率(万分之几) × 逾期天数
如：万分之五/天，逾期 40 天，逾期金额 100 万
   → 1,000,000 × 0.0005 × 40 = 20,000 元，从收益中扣除
```

- 日利率、起扣阈值、封顶规则可配置。
- 支持结合"应收周转率"（`销售额 / 日均应收`）做整体健康度评价。

### 4.3 预收账款计息（正向激励）

与应收相反，**预收账款**（客户先款后货）为公司提前占用了客户资金、降低了资金成本与坏账风险，应对销售员给予**正向激励**：

```
预收计息收益 = 预收账款金额 × 日利率 × 占用天数
个人所得    = 预收计息收益 × 分配系数
如：预收 80 万，占用 25 天，日利率万分之五
   → 800,000 × 0.0005 × 25 = 10,000 元 → 计入销售收益(按分配系数分配)
```

- 与应收利息核算(4.2)方向相反、口径对称：应收逾期计息为**扣减**，预收占用计息为**加项**。
- 日利率可与应收采用同一套或独立配置；是否设封顶、起算阈值可配置。
- 计息基础数据（预收余额、占用天数）来自 ERP 每日快照（见数据篇）。

> **净资金贡献视角（可选汇总）**：`资金净收益 = 预收计息收益 − 应收逾期利息扣减`，可作为销售员"资金运用能力"的综合评价项。

## 五、销售绩效核算示例（月度 · 现货销售员）

绩效基数 6000 元：

| 项目 | 取值 | 说明 |
| --- | --- | --- |
| 基础绩效系数 | 1.0 | 保底销量/新客/客情评分达标 |
| 基础绩效工资 | 6000 | |
| 当月销量 | 800 吨（现款300吨 + 30天账期500吨） | 逐单按账期计提 |
| 吨位提成(阶梯×账期) | 300×8 + 500×6 = 2400 + 3000 = 5400 | 现款8元/吨、30天账期6元/吨 |
| 挂价利润 | (成交-挂牌)差 × 800 = 8000 | |
| 分配系数 | 0.7 → 挂价个人所得 5600 | |
| 预收计息收益 | 预收50万×25天×万5 × 0.7 = 4375 | 正向激励(4.3) |
| 提成小计 | 5400 + 5600 + 4375 = 15375 | |
| 应收扣减(部分逾期20天,扣10%) | −540 | 扣款模式(4.1) |
| 行政奖惩 | 0 | |
| **最终应发** | 6000 + 15375 − 540 = **20835** | |

## 六、销售绩效配置要点

- 业务类型主数据（现货/零调/直发/民调）与规则集路由。
- 吨位阶梯表、挂价分配系数、净利润分成比例。
- **回款账期分档表**：账期分档 + 各档吨位单价 / 提成系数（逐单生效）。
- 净利润口径（其他收入/支出科目映射）。
- 应收考核模式选择与参数（扣款比例表 / 日利率）。
- **预收账款计息参数**（日利率、占用天数口径、分配系数、封顶/阈值）。
- 基础绩效评分卡（维度、权重、系数映射）。

> 取数与计算实现见 [数据与核算引擎设计](./05-数据与核算引擎设计.md)。
