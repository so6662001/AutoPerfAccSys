# 09 · 双真实案例对比与通用能力沉淀清单

> 对比「超扑越」与「岳洋通」两套真实钢贸绩效方案，抽取应沉淀为**平台通用能力**的清单（区分共性能力 / 参数化配置 / 客户专项），指导后续开发优先级。

---

## 一、两套方案速览对比

| 维度 | 超扑越 | 岳洋通 |
| --- | --- | --- |
| 薪酬结构 | 基本工资 + 自营/外配/吨量/加磅 提成 | 销量绩效 + 差价绩效 + 加工绩效 + 新户 + 团队系数 |
| 提成分档维度 | **淡旺季（时间）** + 销量阶梯 | **库别** + 分支机构 + 机构+类别 |
| 计量口径 | 吨量（出库） | **理算重量**（理论计重）+ 内部销售折半 |
| 达成率机制 | 综合达成率(吨70%+利润30%)→**固定档位底薪**；上月定下月 | 团队完成率(分支)→**系数**乘销量+差价 |
| 差价/利润计算 | 过磅=成交−底价；点数=挂价快照 | 现货=(成交−挂牌−20)/10；非现货=(利润2/重量−10)/10 |
| 低价销售 | 扣 20%（多豁免） | 备案则**不算差价绩效** |
| 新客户激励 | 地推纯新客户 **10 元/个** | 开发新户 **前3月各50元** + 外地累计吨量 1 元/吨 |
| 计息 | 无 | **期货合同定金+货物滚动计息**（总额封顶） |
| 过磅业务 | **加磅利润提成**（加磅千分比） | 无 |
| 明细要求 | 明细表·四类提成·按日期不跨月 | 明细（销量/差价/加工）·按库别/日期 |

---

## 二、共性 vs 差异

### 共性诉求（→ 应沉淀为平台通用能力）
1. 多提成项相加的薪酬结构。
2. 阶梯 / 分档提成 + **起步门槛 / 阶跃**。
3. 达成率 / 完成率 → 系数或金额。
4. 计量口径可配（吨量 / 理算重量 / 内部折半）。
5. 低价销售的**条件扣减 / 豁免**。
6. **新客户开发激励**（按个 / 按月固定 / 累计阶段）。
7. **单据级绩效明细报表** + 日期筛选（不跨月）。
8. 业务/库别/组织维度路由到不同规则。

### 差异诉求（→ 参数化配置 或 客户专项）
- 时间维度（超扑越淡旺季）vs 库别+机构+类别维度（岳洋通）→ 统一抽象为**多维参数作用域**。
- 过磅（加磅提成、点数挂价快照）→ 超扑越专项。
- 期货合同滚动计息 → 岳洋通专项（可复用到同类期货/分期业务）。
- 跨期引用（上月定下月底薪）→ 超扑越触发，属通用能力。

## 三、通用能力沉淀清单（含优先级与覆盖）

| --- | --- | :---: | :---: | :---: | :---: |

## 四、建议开发优先级（沉淀顺序）

- **第一批（P0 · 平台地基，两客户都用）**
  1. 多维参数作用域引擎（时间/组织/类别/库别/人员逐级覆盖）；
  2. 计量口径可配（理算重量、内部折半）；
  3. 达成率/完成率映射增强（→固定金额、跨期引用）；
  4. 阶梯/门槛/阶跃通用化（起步门槛、每 N 元阶跃、整体档位/累进切换）。
  → 完成后，两套方案的**主体**即可纯配置落地。

- **第二批（P1 · 强需求，跨客户复用）**
  5. 条件扣减/豁免规则；6. 单据级绩效明细报表；7. 新客户开发激励（按个/按月/累计）；8. 规则例外/保底；9. 团队/组织系数。

- **第三批（P2 · 专项，可按客户排期）**
  10. 合同分笔滚动计息（岳洋通期货）；11. 过磅业务能力（超扑越加磅/点数挂价）；12. 加工费提成。

---

## 五、结论

两套真实方案 **85% 以上的差异**都可归入 **① 多维参数作用域、② 计量口径、③ 达成率映射、④ 阶梯门槛阶跃** 这四项 P0 通用能力——把它们做扎实，平台就能以"配置"方式吃下大部分钢贸客户；剩余为新客户激励、团队系数、规则保底（P1 通用）与 计息扩展、过磅、加工费（P2 专项）。这印证了本系统"**可配置核算项 + 公式引擎 + 参数化规则**"的架构方向是正确的，后续投入应集中在 **P0 四项地基能力** 的通用化上。
