# 钢铁企业自动化绩效核算系统 · 产品设计方案

> 面向钢铁贸易 / 加工 / 生产制造企业的自动化绩效核算平台。基于 ERP 数据源，以"可配置的取数逻辑 + 可配置的核算规则"为核心，实现采购、销售等岗位绩效的自动计算、核定与发放。

## 高保真原型

交互原型位于 [`../prototype/`](../prototype/index.html)，用浏览器打开 `prototype/index.html` 即可浏览（纯静态 HTML，可离线）。包含 16 个界面：管理驾驶舱、核算工作台、个人绩效单（下钻追溯）、审批流、申诉复核、绩效试算器·销售/·采购、政策沙盘·销售/·采购、采购/销售绩效看板、绩效规则配置中心（评分卡/系数/账期/计息可编辑、系数分布回溯、发布走三级串签审批、灰度试点与推广、版本时间轴与 diff）、合规审计查询、数据集成中心（字段/品规映射可编辑）、行情价与价格竞争力、员工端移动绩效（消息中心）。规则治理形成"配置→模拟→审批→灰度→推广→追溯→审计→知会员工"完整闭环。另含「超扑越」真实客户落地案例专属原型 4 页：落地总览(三期路线图)、方案配置(按三期分档)、专属试算器(五项提成实时演算·淡旺季自动切换)、绩效明细表(四类提成分列·按日期筛选不跨月)。

## 一页纸速览

- **目标用户**：钢铁贸易/加工企业的采购、销售岗位（一期核心），HR/财务/管理层为使用与审批方。
- **核心价值**：把散落在 ERP、行情平台、考勤系统中的数据，通过统一的"取数规则 + 核算规则"引擎，自动算出每个岗位/每个人的绩效工资、提成、奖惩，替代 Excel 手工核算。
- **产品骨架**：数据接入层 → 指标计算层 → 绩效核算引擎（规则/系数/公式可配置）→ 核算结果与审批 → 报表看板与发放。
- **设计主线**：一切"取数逻辑"和"核算规则"都由业务/HR 可视化配置，系统只负责按周期跑批计算，做到"规则透明、结果可追溯、口径可复算"。
