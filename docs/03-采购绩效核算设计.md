# 02 · 采购绩效核算设计

采购岗位对采购成本负责，主责现货采购与临调采购。绩效由 **绩效奖金（基础绩效）+ 超额奖（提成）+ 基础量系数** 构成。

---

## 一、采购绩效总模型

```
采购绩效总额 = 基础绩效工资 + 超额奖(变动激励) + 行政奖惩
其中：
  基础绩效工资 = 绩效基数 × 基础绩效系数(0/0.6/0.8/1.0/1.2)
  超额奖       = (行情波动利润 + 实际购销盈亏 + 其他业务收益) × 提成规则 × 分配系数
  最终应发     = (基础绩效工资 + 超额奖) × 综合奖金系数 + 行政奖惩
```

> 综合奖金系数由"基础业务量完成度"驱动，对绩效与超额奖**整体打折**，可能 <1.0 甚至为 0。

---

## 二、核心考核指标体系

### 2.1 采购价格竞争力（能力项）

**定义**：日常采购进价与市场同期行情价对比，评判是否拿到有竞争力的低价。

**计算逻辑**：

```
单笔价差率 = (行情基准价 - 实际采购单价) / 行情基准价
采购价格竞争力得分 = Σ(单笔价差率 × 采购吨位) / Σ采购吨位    (加权平均)
```

- 价差率 > 0：低于市场，加分；< 0：高于市场，扣分。
- **行情基准价匹配维度**：品名 × 规格 × 材质 × 地区 × 采购日期（就近取样）。
- 数据来源：钢银 / 钢之家 平台对接，或人工导入（见数据篇）。
- 结果映射为得分或直接进入系数评分卡。

### 2.2 行情掌控能力（能力项）

**定义**：评估采购员对上游厂家价格后续行情涨跌的判断与推演能力——即"在低点囤货、在高点观望"的择时能力。

**量化思路（可配置）**：

```
采购择时收益 = Σ [ (采购后 T 日行情价 - 实际采购价) × 采购吨位 ]
             （T 为观察窗口，如采购后 7/15/30 日）
择时命中率  = 采购后行情上涨的批次数 / 总采购批次数
```

- 正收益说明"低买"判断准确；负收益说明踏错节奏。
- 结合"命中率 + 择时收益额"综合评分，避免单靠运气。
- 可叠加主管定性打分（判断报告、行情研判质量）。

### 2.3 存货与资金效率（结果项）

**(a) 存货周转率**（避免积压产生财务成本）

```
日均库存   = Σ(每日库存快照) / 考核期天数           （平台自动，见数据篇）
存货周转率 = 期间销售量(或销售成本) / 日均库存
存货周转天数 = 考核期天数 / 存货周转率
```

- 越高越好；设目标值/区间，映射到系数评分卡。
- 结合资金成本：`积压资金成本 = 超期库存金额 × 资金成本率 × 天数/365`，可作为扣减项。

**(b) 应付/预付结构合理性**

```
结构健康度：可配置规则集，示例——
  - 若 预付账款 = 0 且 应付账款 > 阈值 → 判定"结构不合理"（占用自有资金）
  - 预付占比 = 预付 / (预付 + 应付)，落在健康区间[a, b] → 合格
  - 支持"评分制"：不同区间给不同分
```

> 🔶 原文"仅有应付而无预付可能不合格"是举例，实际以可配置的**结构健康度规则**落地，由业务设定阈值/区间/评分。

## 三、超额奖（提成）核算逻辑

超额奖 = 采购员创造的经济收益 × 提成规则。收益由三部分构成：

### 3.1 行情波动利润（择时创造的利润）

```
行情波动利润 = Σ [ (卖出/重估时点市场价 - 采购成本) × 对应吨位 ]
```

- 反映利用行情涨跌波动创造的价值。
- 需与"实际购销盈亏"去重，避免同一收益重复计入。

### 3.2 实际购销盈亏（真实购销周期盈亏）

```
实际购销盈亏 = Σ [ (实际售价 - 采购成本 - 相关费用) × 吨位 ]
```

- 反映一进一出的真实盈亏。

### 3.3 成本重估（关键难点 · 剔除偶然性收益）

> 需求原文："需重新评估成本价格，排除因市场偶然因素（瞎猫碰死耗子）带来的非能力性收益。"

**设计：可配置的成本基准法（业务侧择一或组合）**

| 方法 | 重估成本口径 | 适用 |
| --- | --- | --- |
| 移动加权平均法 | 按批次移动加权计算成本 | 常规现货 |
| 市场基准价法 | 以采购时点行情基准价作为"应然成本" | 剥离运气：只认相对市场的能力差 |
| 批次实际成本法 | 按实际批次成本 | 强追溯场景 |

**剔除偶然性收益的逻辑**：

```
能力性收益 = 实际收益 - 市场自然波动收益
  其中 市场自然波动收益 = (期末市场价 - 期初市场价) × 吨位
即：把"随大盘上涨白赚的部分"剔除，只奖励"跑赢市场"的部分。
超额奖计提基数 = MAX(能力性收益, 0) 或按配置允许负值对冲
```

> 该口径把"行情普涨带来的账面利润"与"采购员真实择时能力"分离，直击"瞎猫碰死耗子"问题。具体是否封顶、是否允许负值，均为可配置项。

### 3.4 其他业务收益

- 外调 / 自发业务产生的获利，纳入超额奖计提范围（独立规则集，比例可不同）。

### 3.5 提成计提（支持阶梯）

```
超额奖 = 计提基数 × 提成规则(固定比例 / 阶梯比例) × 个人分配系数
阶梯示例：
  收益 ≤ 50万      → 5%
  50万 < 收益 ≤ 100万 → 8% (超额部分)
  收益 > 100万      → 12%(超额部分)
```

---

## 四、综合奖金系数（基础量约束）

**作用**：基础业务量不足时，对"基础绩效 + 超额奖"整体打折。

```
基础量完成率 = 实际基础采购量 / 目标基础采购量
综合奖金系数 = 查表(基础量完成率)      示例映射：
  完成率 < 60%        → 0      （无奖金）
  60% ≤ 完成率 < 80%  → 0.6
  80% ≤ 完成率 < 100% → 0.8
  100% ≤ 完成率 <120% → 1.0
  完成率 ≥ 120%       → 1.2
```

- 与"基础绩效系数"是两个概念：基础绩效系数调节**基础绩效工资**；综合奖金系数调节**整体（含超额奖）**。可按企业政策决定是否叠加或二选一。

## 五、采购绩效核算示例（月度）

假设某采购员，绩效基数 8000 元：

| 项目 | 取值 | 说明 |
| --- | --- | --- |
| 基础绩效系数 | 1.0 | 价格竞争力/行情掌控/周转综合评分达标 |
| 基础绩效工资 | 8000 × 1.0 = 8000 | |
| 能力性收益（重估后） | 60 万 | 已剔除市场普涨部分 |
| 提成（阶梯 5%~8%） | 50万×5% + 10万×8% = 3.3万 | |
| 个人分配系数 | 0.8 | |
| 超额奖 | 33000 × 0.8 = 26400 | |
| 基础量完成率 | 85% → 综合系数 0.8 | 基础采购量略欠 |
| 小计（打折前） | 8000 + 26400 = 34400 | |
| × 综合奖金系数 0.8 | 27520 | |
| 行政奖惩 | −200（迟到扣款） | |
| **最终应发** | **27320** | |

## 六、采购绩效配置要点（给 HR/业务）

- 行情价基准表维护（对接优先，人工导入兜底）。
- 成本重估方法选择与参数（窗口 T、是否封顶、是否允许负值）。
- 提成阶梯表、分配系数。
- 基础量目标、两类系数的档位映射表。
- 存货/应付预付结构健康度规则阈值。

> 所有以上均为可视化配置 + 版本化管理，政策调整不改代码。计算细节见 [数据与核算引擎设计](./05-数据与核算引擎设计.md)。
